# Card fonts

Used only at build time by the card and pack compositors (text is converted to vector paths, so nothing is loaded at runtime).

| File | Font | License |
| --- | --- | --- |
| `LuckiestGuy-Regular.ttf` | Luckiest Guy by Astigmatic | Apache License 2.0 |
| `LilitaOne-Regular.ttf` | Lilita One by Juan Montoreano | SIL Open Font License 1.1 |

`RubikGlitch-OFL.txt` is the licence text for Rubik Glitch by NaN and Luke Prowse (SIL Open Font License 1.1), whose subset `src/assets/fonts/RubikGlitch-Latin.woff2` is the site's logo wordmark; the pack art no longer draws it, so its build copy was removed.

All downloaded from [google/fonts](https://github.com/google/fonts).
