# Agent guide

This is a pointer for agents that don't load CLAUDE.md automatically.

- Repo rules (layers, compatibility, saves, commit identity): [CLAUDE.md](CLAUDE.md).
- Workflow and checks: [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).

Never break these:

- Released sets and old proofs are permanent. Changes that alter them need a new set, ticket or proof version.
- Saves and player keys are private. Don't commit, upload or post them.
- Never push to main. Work on a feature branch and open a pull request.
